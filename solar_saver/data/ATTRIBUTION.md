# Data attribution

Solar Saver uses the following external data sources:

- Solar irradiance and historical meteorological data: NASA Prediction Of
  Worldwide Energy Resources (POWER), https://power.larc.nasa.gov/
- Historical forecast and live forecast weather data: Open-Meteo,
  https://open-meteo.com/. Weather data is used under the CC BY 4.0 licence;
  see https://open-meteo.com/en/terms.

The trained model combines NASA POWER irradiance targets with Open-Meteo
forecast-style cloud cover, temperature, relative humidity, and precipitation.
Neither data provider endorses Solar Saver.
